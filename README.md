# PY POS — trang giới thiệu

Một file `index.html` duy nhất, không build, không phụ thuộc gì. Chứa ở
GitHub Pages: <https://trancaoviet7514.github.io/py-pos/>

Đây là **bản chép** từ `website/index.html` trong repo app (private). Sửa ở
bên đó trước rồi chép sang, đừng sửa trực tiếp ở đây — hai bản lệch nhau
thì lần chép sau sẽ đè mất.

Repo này công khai và chỉ có đúng trang HTML này: không có mã nguồn app,
không có dữ liệu quán, không có khóa nào.

Trang xem báo cáo là một trang khác, ở repo `py-pos-bao-cao`.
